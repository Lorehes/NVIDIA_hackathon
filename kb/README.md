# 공식 도메인 KB

`entities.json`은 수동 등록한 사칭 대상 기관과 공식·파트너 도메인의 원본이다. 대규모 명부 주소는 아래의 `site_catalog.json`에서 별도로 읽는다.

## 지금 들어 있는 것

실제 기관·서비스 15개와 가상 브랜드 2개(한빛택배, 하늘은행). 가상 브랜드 도메인은 예약 TLD(`.example`)다.

실제 항목: 우체국, CJ대한통운, 한진택배, 롯데택배, 로젠택배, KB국민은행, 우리은행, 하나은행, IBK기업은행, 국세청, 국민건강보험공단, 정부24, 관세청, 금융위원회, 대한민국 정책브리핑.

2026-09-25 각 공식 사이트에서 도메인을 확인하고 출처·확인 날짜를 기록했다. 실제 기관의 파트너 도메인과 금지 입력 정책은 아직 검증하지 않아 비워 뒀다. 빈 정책을 “아무 입력이나 안전하다”로 해석하지 않는다.

`tests/test_real_kb.py`는 기관별 이름 검색, 공식 페이지, 위장 서브도메인, 접속 미확인 사례를 검증한다(60개). 이 통제된 오프라인 테스트는 실제 문자 수집 데이터에 대한 오탐·미탐 평가를 대체하지 않는다.

## 실제 기관을 추가하려면 (상세 명세 7절)

- **각 기관의 공식 사이트에서 직접 확인한 도메인만** 넣는다. 기억이나 검색 결과로 채우지 않는다.
- `sources`에 도메인을 확인한 공식 페이지 URL과 확인 날짜를 반드시 적는다.
- 확인하지 못한 기관은 넣지 않는다. (KB에 없는 기관은 "알 수 없어요/조심하세요"로 안내되고, 거짓 "가짜" 판정을 내지 않는다.)
- 도메인은 등록 도메인 단위로 적는다(`example.co.kr`처럼 다단계 접미사 포함).
- `fictional: false`로 표시한다.
- `policy_rules[].forbids`: 그 기관이 문자·링크로 요구하지 않겠다고 밝힌 입력란(`password`, `card_number`, `card_cvc`, `card_expiry`, `bank_account`, `resident_id`, `otp`).
  판정 엔진이 이 값으로 "회사 약속과 달라요"를 계산한다.

## 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 영문 소문자 식별자 |
| `name` | 필수 | 표시 이름 |
| `aliases` | 필수 | 문자에 쓰일 수 있는 별칭 |
| `category` | 필수 | delivery, bank, card, government, telecom, fictional |
| `official_domains` | 필수 | 등록 도메인 단위 |
| `partner_domains` | 선택 | 공식적으로 쓰는 인증·결제 대행 도메인 |
| `policies` | 선택 | 표시용 문구 |
| `policy_rules` | 선택 | 엔진용 구조화 규칙(위 참고) |

| `fictional` | 필수 | 가상 브랜드 여부 |

## 대규모 출처 카탈로그

수동 기관 17개와 별도로 `site_catalog.json`을 정확 주소 인덱스로 읽는다. 정부/학교/병원 공식 명부, 검토된 운영자의 서비스 목록과 한국 인기 선정 1,000개를 합친 자료다. 인기 자료는 공식 신원 근거가 아니다. 최신 포함/제외 개수는 `sources/coverage.json`, 진행/누락은 `docs/2026-09-25-catalog-progress.md`를 확인한다. 수집은 `scripts/catalog/collect_*.py`, 생성은 `scripts/catalog/build_catalog.py`로 재현한다. 공식 서비스 목록은 `sources/service_publishers.json`의 검토된 출처/추출 설정을 사용하며 파파고 등 개별 사이트의 판정 예외는 두지 않는다. 출처 페이지의 단순 광고/소셜/앱스토어 연결을 운영사 전체 주소로 승격하지 않는다.

명부의 선두 BOM 또는 단일 절대 URL 앞의 정확한 `홈페이지` 필드 문구는 분리하고 원문/정규화 이유를 보존한다. 문구를 분리한 주소는 정확 URL 범위로 제한한다. 주소 철자·내부 공백·복수 값은 추정 수정하지 않으며, 제외와 검사 제한을 coverage.json에서 별도로 보고한다.

부분 갱신은 `collect_services.py --source <검토된 출처 URL>`로 실행한다. 갱신하지 않은 행의 확인일을 보존하며 수집기·앱은 UTC 날짜를 사용한다. 공식 서비스 루트에서 실제로 관찰한 같은 등록 경계의 HTTPS 루트 이동은, 조건을 충족하면 해당 조사에서만 정확한 도착 주소의 근거가 된다. 질의가 붙은 도착 주소를 공용 카탈로그에 저장하거나 호스트 전체에 신원을 부여하지 않는다. 이 기능은 학교 간 이동이나 인기 자료에 적용되지 않는다.

명시된 계열사 목록은 검토한 구역 제목과 구조가 일치할 때만 별도로 추출한다. `official_affiliate_directory`/`publisher_affiliate_link`로 서비스 연결과 구분하고 정확 URL만 등록한다. 그룹 내 각 회사를 하나의 운영사로 합치지 않으며 계열사의 모든 서비스·하위 주소를 승인하지 않는다. 제목·구조가 바뀌거나 중복 구역이 나타나면 갱신을 중단하고 기존 자료를 보존한다. 일반 하단 링크·블로그·채용·약관은 수집 대상이 아니다. 계열사 연결에는 서비스 루트의 조사 중 이동 신원 승격을 적용하지 않는다.

공식 자료를 대조해 보완한 기관 주소는 `sources/verified_corrections.json`에 원자료 식별자·원주소·확인일·근거를 보관한다. 자료집/식별자/이름/원주소가 정확히 일치하는 단일 행에만 적용하며 원자료 변경·중복·기한 초과는 적용하지 않고 보고한다. 원자료 자체를 덮어쓰지 않으며 이름 유사도나 철자 추정으로 주소를 만들어 등록하지 않는다.

넥슨 게임 명부는 공식 페이지의 공개 JSON 데이터 연결을 대조한 뒤 `gameList`의 PC/모바일 홈페이지 필드만 읽는다. 게임별 하드코딩 판정은 없으며 수집 경로·응답 성공 값·필드 경로·개수 상한을 출처 설정으로 관리한다. 중복 JSON 키, 바뀐 구조/연결, 오류 응답이면 기존 스냅샷을 유지한다. 배너·스토어·커뮤니티는 홈페이지 필드로 대체하지 않는다. PC와 모바일이 같은 URL이면 근거 필드를 합치고, 다른 URL이면 각각 정확 주소로 등록한다. HTTP 원문·질의는 보존하며 단축 주소의 다른 경로나 이동 목적지를 자동 승인하지 않는다. 게임 목록 등재는 출시·운영 상태나 모든 사용자 콘텐츠의 안전성 확인이 아니다.

기관 식별자가 없는 명부 행은 이름만으로 보완하지 않는다. 별도 검토 설정에 원문 행 전체와 자료집 전체의 정규 JSON SHA-256을 함께 기록하고, 그 자료 버전에서 유일한 행과 기관명·원주소가 모두 일치할 때만 적용한다. 키 순서·들여쓰기는 해시에 영향을 주지 않지만 확인일·행 내용·행 순서 등 자료 내용이 바뀌면 재검토 전까지 적용을 중단한다. 행 해시는 기관 식별자로 표시하지 않으며 기존 source_id를 만들거나 원자료를 수정하지 않는다. 자료 버전이 갱신되면 이전 검토를 자동 이전하지 않는다. 기존 식별자 기반 보완과 함께 정확 URL 범위·90일 근거 유효기간·중복 거부·원문 보존을 유지한다.

`collect_education.standard()`의 보건기관·대학 표준자료 갱신은 `sources/refresh_candidates/<자료집>.json`에 검토 후보로 저장한다. 활성 원자료와 보완 설정은 자동 교체하지 않는다. 후보에는 활성 자료/보완 설정 해시, 새 자료 해시, 적용되지 않는 기존 보완 및 동명이 개수가 있다. `source_context`에는 공식 열 코드와 한글 설명이 함께 확인된 지역·주소·기관 유형·제공기관 정보만 원문 그대로 보존한다. 제공기관 코드는 개별 학교/보건소의 고유 ID가 아니므로 `source_id`로 만들지 않는다. 전화번호와 기타 열은 보존하지 않는다. 이름·주소 오기는 고치지 않는다.

갱신 주기에 후보를 수집한 뒤 지역/주소와 공식 기관 근거를 대조하고, 변경·누락 행과 비활성 보완을 검토해야 한다. 후보의 기준 해시가 여전히 활성 자료와 일치하는지 확인하고 보완 근거를 새 자료 버전에 맞게 재검토한 후 원자료를 교체·카탈로그 생성·관련 검사를 수행한다. 후보 생성 자체는 앱 등록이 아니며 기존 행 해시를 새 자료로 자동 이전하지 않는다. 현재 이미 수집된 자료의 지역 정보가 소급 복원되는 것도 아니다. `build_catalog.py`는 후보 디렉터리를 읽지 않는다. NEIS 학교 수집은 기존 별도 경로이며 이 표준자료 변경의 대상이 아니다.

공식 서비스 목록의 비루트 홈페이지도 조사 중 실제 HTTP 이동을 근거로 확인할 수 있다. 최근7일 출처의 정확 URL에서 시작해 같은 HTTPS 호스트의 해당 경로 안에 머무르는 경우만 적용한다. 실제 도착한 정확 주소 하나에 한정하며 경로 전체 허용이나 영구 저장이 아니다. 출발/도착 질의, 인코딩된 모호한 경로, 다른 경로·호스트·학교·공유 서비스에는 적용하지 않는다. 출처가 있는 주소의 이동 확인과 페이지 행동/TLS 안전성은 별개다. 상세 경계와 회귀 증거는 `docs/2026-09-26-service-path-redirect.md`를 참고한다.

### 검토한 검색 관계

`sources/reviewed_search_relations.json`은 공식 출발 URL·기관 id·카탈로그 원항목 해시·정확 목적지·메서드·공식 운영 근거를 검토한 검색 연결이다. 24시간 이내만 적용하며 만료/변경/민감 입력/다른 폼을 자동 면제하지 않는다. 판정기에 도메인 조건을 추가하지 않고 데이터와 출처를 대조한다. 공식 관계가 확인되어도 실제 전송 미검사를 남겨 safe를 막으며, 네트워크 권한이나 목적지 호스트 전체 신원으로 사용하지 않는다. 자동갱신 없음. 근거를 다시 확인한 후 갱신한다.
