# 파일 첨부란 누락과 검색 전용 분류 개선

2026-09-26. 파일 첨부 input이 검사기에서 제외되어, 검색 입력과 파일 첨부가 섞인 폼을 검색 전용으로 간주하거나 파일 첨부만 있는 공식 페이지를 입력란 없는 페이지로 표시할 수 있었다.

파일 입력을 별도 file 유형으로 관찰한다. 파일 형식은 이름/자동완성 속성이 password·cc-number처럼 보이더라도 파일 선택이라는 실제 입력 유형을 우선한다. 다른 폼에 연결된 form 속성과 대문자 FILE, multiple/accept 조건도 검증했다. 파일이 포함된 폼은 search_only/same_origin_search 예외 대상이 아니며, 공유 기관의 다른 처리 경로와 외부 전송은 기존 경고를 유지한다. hidden 검색 토큰만 있는 정상 검색은 기존 처리 그대로다. 사이트 이름이나 만족도 문구에 따른 예외를 추가하지 않았다.

공식 주소의 파일 첨부 자체를 악성으로 분류하지 않는다. 공식 신원은 유지하며 첨부할 파일 내용·실제 전송·서버 처리를 미검사로 표시하고 safe로 승격하지 않는다. 비교 및 상세 기록에 첨부 파일/첨부 내용 미검사를 표시한다. 첨부 파일을 실제로 열거나 전송하지 않는다. 알려진 파일 내용을 수집/저장하지 않는다.

웹 상세 기록의 기본 문구에도 ‘보내는 곳이 없어요/페이지 안에서만 쓰여요’가 남아 있어, 전송 주소 미표시/실제 처리 미검사로 수정했다. API에서 설명을 누락하거나 구형 자료를 표시해도 서버 내부 처리를 단정하지 않는다. 새 unknown 입력 상태는 중립 표시이며 프런트/응답모델을 함께 확장했다.
