# 삼성 공식 앱·서비스 출처 확장

2026-09-26. 삼성전자 공식 앱·서비스 목록 `https://www.samsung.com/sec/apps/`의 서비스 카드 연결24개를 수집했다. 검토한 `apps-service-link` 선택자와 링크 제목을 기존 일반 수집기에 설정했다. 하단 고객지원·약관·앱스토어·제품 구매 링크는 목록에 포함하지 않는다. 이24개는 공식 서비스 안내 페이지이며 실제 웹앱 시작 주소24개라고 표현하지 않는다.

추가로 Samsung Find 안내 페이지 `https://www.samsung.com/sec/apps/samsung-find/`의 ‘시작하기’ 연결 `https://samsungfind.samsung.com/login`, 삼성 클라우드 안내 페이지 `https://www.samsung.com/sec/apps/samsung-cloud/`의 ‘삼성 클라우드로 이동’ 연결 `https://www.samsungcloud.com`을 확인했다. 두 목적지는 직접 HTTPS200, HTTP 이동 없음, 제목 Samsung Find/Samsung Cloud. 로그인·위치 조회·계정 접근·폼 제출은 하지 않았다. 클라우드의 ‘더 알아보기’ 및 별도 스마트폰 구매 링크는 서비스 시작 주소로 채택하지 않았다.

추가26건 모두 정확 URL 범위다. 앱 코드에 삼성 도메인 예외 조건을 추가하지 않았으며 삼성 전체 하위 도메인이나 로그인 이후 경로로 신원을 확장하지 않는다. 기존230개 서비스 행의 날짜·내용과 기존22,165개 카탈로그 레코드가 모두 불변임을 확인했다. 부분 수집은 위3개 출처만 갱신하며 다른 출처의 검증 날짜를 연장하지 않는다.
