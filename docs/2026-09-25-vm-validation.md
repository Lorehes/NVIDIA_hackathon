- 작업 ID의 밑줄은 정책 이름에서 하이픈으로 정규화한다. 추가·회수에 동일한 이름을 사용한다.

1. VM에서 두 서비스를 확인하고 `bash infra/scripts/check-residual-policies.sh`가 성공하는지 확인한다.
2. 로컬에서 `brev port-forward nemoclaw-d3f195 -p 3310:3100`으로 접속 경로를 만든다.
3. `http://localhost:3310/?demo=1`을 열어 시연 모드 배너를 확인한다. 예시 버튼 5개는 픽스처 기반 저장 결과다.
4. 입력 → 진행 → 판정·근거 → 상세 기록 순으로 보여준다. 위장 주소 사례의 이 흐름과 상세 기록 진입을 브라우저에서 확인했다.
5. 실제 실행을 재생하려면 시연 모드에서 `https://example.com`을 입력한다. `vm-example.json`은 위 실제 작업에서 저장한 결과이며, 재생 데이터 재생성 명령이 덮어쓰지 않는다.
6. 실시간 조사는 시연 모드를 끄고 실행한다. 모델 과부하 시 기본 설명 또는 중단 표시가 나올 수 있다. 실제 기관 확인과 입력 위험을 구분해 설명한다.

실제 결과 원본: `apps/api/data/replay/vm-example.json`. 재생 속도는 원래 측정 시간과 별개다. 로컬 포트 전달 연결을 복구해 HTTP 200과 시연 배너·실제 결과 재생 진입을 다시 확인했다. 수정 후 실제 캡처의 입력→진행→결과 및 상세 5탭(주소·이동 경로·페이지·AI·안전 공간)을 브라우저에서 모두 확인했다. 최종 발표 녹화는 아직 완료하지 않았다.
