# 카탈로그 공유 주소 범위 감사와 제외 자료 분류

2026-09-25. 기존 원자료를 다시 내려받지 않고 저장된 출처 자료로 재현했다.

## 수정

- 특정 경로/질의가 명부에 등록된 경우에는 같은 호스트에서 기관 이름이 하나만 발견돼도 정확 URL 범위를 적용한다. 기존 호스트 범위 775건을 좁혔다.
- 예: 유치원 명부에 있는 bit.ly/3IuoU6C가 다른 단축주소까지 해당 유치원으로 인정하던 문제를 차단했다. 해당 단축주소의 최종 목적지 안전성을 확인했다는 의미는 아니다.
- 학교 원문 2행의 선두 내보내기 BOM만 제거했다. 원주소와 변환 사유를 카탈로그에 보존한다. 내부 공백·철자·설명·복수 주소는 임의 수정하지 않았다.
- 등록 레코드21,794건/호스트16,135개, 인기 선정1,000개. 공식 자료 호스트 범위12,420건/정확 URL 범위8,374건.

출처·원주소·제외 사유는 kb/sources/coverage.json의 excluded 및 excluded_source_reasons에 저장했다. 등록 자료 자체의 오기·폐지·이전·정확한 소유 범위는 별도 검증 과제이며 공식 명부에 실렸다는 사실만으로 현재 페이지 안전성을 보증하지 않는다.

## 검증

로컬 주소/출처 회귀24개 통과. 단일 기관 공유 경로와 질의, 다른 단축주소, 전체 등록 경로 범위, BOM 원문 보존, 제외 사유 합계 일치를 검사했다. VM 배포·카탈로그 재생성 후 전체508개 통과(67.04초, 기존 Starlette 사용 중단 예정 경고1개). 실제 등록 주소의 KB 조회에서 원래 경로는 verified/미등록 다른 경로는 unverified, 파파고 공식 확인 유지, API health HTTP200 확인. 로컬/VM 카탈로그 해시 일치. 이 결과는 단축주소 목적지에 대한 실제 접속 검증이 아니다.
