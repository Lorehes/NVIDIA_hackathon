# 공유 홈페이지의 복수 기관·서비스 표시

같은 주소를 쓰는 초등학교·병설유치원과 여러 서비스가 모두 등록되어도 결과에 이름 하나만 표시되던 문제를 보완한다. 개별 사이트 이름을 앱 분기에 넣지 않고 기존 출처·주소 범위 일치 결과를 모두 모은다.

- 기존 대표 항목 선택과 판정은 유지한다. 유효한 공식 자료의 일치 항목만 `matched_entities`에 포함하고 이름 중복을 제거한다.
- 최대20개 이름과 공식 출처를 표시하고 전체 이름 수는 별도로 전달한다. 초과 항목 수를 숨기지 않는다.
- 정확 URL 자료는 호스트·포트·경로·질의 일치를 유지하며 다른 경로, 미등록 하위 호스트, 다른 포트, 오래된 자료, 인기 등재만 있는 자료는 공식 이름에 포함하지 않는다.
- 기존 호스트 범위 자료는 기존 범위 안에서 일치한다. 새 호스트/경로 신원이나 통신 권한을 만들지 않으며 공유 기관을 하나의 기관으로 병합하지 않는다.
- 공식 이름이 여러 개라는 이유로 페이지 동작이나 TLS를 안전하다고 처리하지 않는다. 과거 저장 결과는 소급 재작성하지 않는다.

## 새로 발견한 미완료 사례 — 다음 우선 작업

NHN PlayArt 조사 `j_7c236a9f866842adafd7033a85ffa0dd`는12.676초에 `https://www.nhn-playart.com/game.nhn`→`http://www.nhn-playart.com/game/`→`https://www.nhn-playart.com:443/game/`,HTTP301/301/200으로 끝났다. 원래 명부 주소는3개 게임과 일치하지만 최종 경로는 명부에 없어 unverified/caution/domain_not_official로 표시됐다. 이번 복수 이름 표시로 고쳐진 사례가 아니다.

기존 관찰 규칙은 HTTPS 루트만 허용하므로 HTTP 중간 이동·새 경로의 신원을 자동 승인하지 않은 것은 의도된 경계다. 다만 출처로 확인된 시작 주소와 미확인 최종 경로를 구분하여 설명하고, 직접 입력 조사에서 기관을 스스로 골라 그 기관과 다르다고 위험 신호를 만드는 동작을 보완해야 한다. 새 경로에 대한 독립 공식 연결 근거를 확보하고 일반 규칙·회귀로 처리할 것. HTTP 이동이나 학교 전체 경로를 포괄 승인하지 않는다.

남은34개 제외 형식/복수값/이메일/IP, 홈페이지 미제공2,539행의 공식 주소 및 기관 상태·누락·이전, 다른 운영사/직접 모바일 공식 근거 확장은 계속 남아 있다. 전체 완료가 아니므로 후속 실행을 유지한다.
