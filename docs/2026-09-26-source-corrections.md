## 재생성 시 적용 조건

`scripts/catalog/source_corrections.py`는 출처 자료집/기관 식별자/이름/원주소가 모두 일치하는 단 하나의 원자료 행에만 보완을 적용한다. 같은 이름의 다른 기관에는 적용하지 않는다. 중복된 보완 설정은 오류로 중단하며, 원자료 변경·행 중복·90일 초과·미래 확인일은 적용하지 않고 coverage.json의 inactive_corrections에 보고한다. 원자료를 갱신하면 과거 보완이 무조건 덮어쓰지 않는다. 새 URL도 기존 URL 유효성 검사를 통과해야 한다. 이 규칙의 공식 근거 자료는 검토 후 추가하는 데이터이며 사이트 판정기의 기관별 예외 조건은 아니다.
