# 한컴 실제 서비스 시작 주소5개 — 구조화 데이터 근거

2026-09-26. 직전 확인한 한컴의 서비스 소개5페이지에 저장된 `__NEXT_DATA__`에서 한국어 `service-contents`의 해당 서비스 `serviceTopBanner` 객체를 찾았다. 각 소개 페이지에 연결된 공개 페이지 스크립트를 읽어 text1/버튼1/link1을 배너로 전달하고 link1이 이동 버튼에 사용되는 구조를 확인했다. 스크립트는 실행하지 않았다. 전체 상태나 개인정보를 저장하지 않고 검토된 추출 설정·필드·응답/스크립트 해시만 증거로 남겼다.

등록 출처는 https://www.hancom.com/service/docs, /service/taja, /service/sign, /service/hform, /service/developer다. 각각 해당 서비스 객체만 읽어 다음 시작 주소를 확인했다.

- 한컴독스: https://www.hancomdocs.com
- 한컴타자: https://www.hancomtaja.com
- 한컴싸인: https://www.hancomsign.com
- 한컴폼즈: https://hform.hancom.com
- 한컴디벨로퍼: https://developer.hancom.com

로컬 직접 HTTPS 요청5개 모두200/이동없음, 제목이 각 서비스와 일치했다. 이 확인은 OpenShell VM 조사나 브라우저 기능 검증을 대신하지 않는다. 문서/설문/서명 제출, 스크립트 실행, 원본 서버 TLS 세부 검증은 하지 않았다. FAQ/포럼/다른 객체/공통 메뉴는 등록 대상이 아니다. 특히 사용자 문서·설문 경로와 다른 하위호스트에는 시작 주소의 공식 신원을 자동 전파하지 않는다.

기존 JSON 목록 수집기에 `group_shape: object` 옵션을 추가했다. 기본 목록 형식을 보존하면서 명시적으로 검토한 단일 객체도 같은 제목/홈페이지 필드 규칙으로 읽는다. 객체가 목록/문자열/null 등으로 바뀌거나 설정 값이 알 수 없으면 거절한다. 기존 중복 JSON 키·실행식·템플릿 URL·사용자정보·잘못된 포트·설치 파일 제외를 유지한다. 특정 서비스 주소를 판정기 조건문으로 넣지 않았다. 검토 스크립트 해시는 근거 메타데이터이며 이 JSON 모드의 자동 갱신 시 스크립트 해시를 재검사하는 기능은 아니다. 공식 페이지의 검토된 데이터 경로/형식과 최소 개수가 갱신 검사의 기준이다.
