## Flowline 정리

웹 배포·재생 구현과 보안 경계·시간 제한·실패 복구 구현을 완료 처리했다. 기존 업무에 섞여 있던 통제 HTTPS 전체 시험·발표 리허설·녹화는 실전 품질 업무로 옮겨 미완료 범위를 보존했다. VM 준비와 기존 실제 조사 E2E는 기존 완료 상태를 유지한다.

## 공식 운영 관계 갱신

`scripts/catalog/refresh_search_relations.py`는 검토된 정확 출발 URL/기관 항목 해시/도착 URL/메서드와 독립 운영 근거를 다시 확인한다. HTML의 현재 검색 폼, 민감 입력 유무, 검색 목적지 제목, 운영 공지의 검토한 문단 해시를 함께 대조한다. 새로 발견한 연결은 승인 후보로만 보고하고 자동 등록하지 않는다.

DNS 공인 주소 확인 후 IP를 고정하여 원래 Host/SNI로 HTTPS 인증서를 검증한다. 리다이렉트·비표준 포트·인증정보 포함 URL은 수집하지 않는다. 응답 크기/시간 제한을 적용한다. 실패한 검토 대상은 즉시 관계 자료에서 제외하고, 확인한 관계만 24시간 갱신한다. 유효시간이 충분하면 재수집하지 않는다. 최초 운영 근거 검토의 90일 기한도 넘기지 않는다.

이는 실행 시 수집·검증을 자동으로 수행하는 도구이며 예약 실행은 아니다. 새 운영사를 신뢰 대상으로 승인하는 검토 자체는 자동화하지 않는다. 관계 확인을 페이지 안전 보증이나 POST 실행 권한으로 사용하지 않는다.

로컬 실제 출처 검증에 이어 VM에서도 충북대 관계 3건 갱신 성공, 실패 0·미검토 후보 0. VM 확인 시각 2026-09-26T08:33:53Z. 관련 48개 VM 검사 통과. 원격 갱신 자료를 로컬로 회수하여 해시를 일치시켰다. 백업 `/tmp/workstreams-deploy-20260926T083345Z`.

`scripts/catalog/audit_coverage.py`가 모든 제외 행에 원자료 연결, 행/자료집 해시, 구분 가능한 지역 문맥과 검토 상태를 부여한다. 동명·중복 식별자·복수 원자료 대응은 추정해서 연결하지 않는다. 자료집이 변경되면 과거 상태 검토를 자동 적용하지 않는다. 동일한 제외 행도 원자료의 각 행으로 보존한다.

현재 유치원 수집기의 식별자는 교육지원청명+유치원명으로 만든 값이다. 전국에 같은 지원청명이 존재할 수 있으므로 공식 고유 식별자로 사용해서는 안 된다. 학교 식별자 중복도 원자료 맥락을 확인해야 하며 이번 분류만으로 타 기관/폐교/중복 기관 중 어느 것인지 단정하지 않는다. 기존 상태 근거 3건은 이번에 새로 발견한 것이 아니라 과거 문서 근거를 구조화한 것이다.

결과는 `kb/sources/coverage_review_queue.json`과 `institution_status_reviews.json`. 명부 전수 운영 상태 확인은 미완료다. 국군의무사령부 홈페이지 조사에서는 TLS 체인 검증 실패가 발생하여 근거 채택을 보류했다. 검증을 끄거나 병원 폐쇄로 판단하지 않았다. 대규모 원자료 재다운로드는 하지 않았다.

## 실전 품질 검증

로컬 전체 API 865개/42.58초, 이후 추가한 자료 감사 5개 통과. 최종 VM 전체 API 870개/70.22초 통과. 기존 Starlette 사용 중단 예정 경고 1개만 있다. 모의 HTTPS/로컬 fixture 검사를 공개 HTTPS 실험으로 표현하지 않는다.

실제 브라우저 리허설에서 끊어진 로컬 연결을 복구하고 입력→결과→상세→재확인을 수행했다. 첫 충북대 조회는 ReadTimeout으로 페이지 미확인, 공식 주소 verified, 전체 unknown, 실효 임시 권한 0. 재확인에서는 공식 검색 연결 설명이 표시되고 전체 unknown을 유지했다. 실패와 성공을 모두 증거에 남긴다.

리허설에서 정상 `www`에도 사칭 의도를 단정하는 상세 화면 문구를 발견했다. 기본 도메인·하위 주소 설명을 중립적으로 바꾸고 실제 위장 신호가 있는 경우만 해당 근거를 설명한다. VM 타입 검사/프로덕션 빌드 및 실제 화면에서 수정 문구를 확인했다. 로컬은 web 의존성이 설치되지 않아 타입 검사를 실행하지 못했고, VM 검증으로 확인했다. 백업 `/tmp/trace-copy-20260926T083902Z`.

## 품질 완료 조건 중 아직 남은 부분

- 통제 가능한 공개 HTTPS 시험 주소에서 E1–E5/S1·S2 전체 수행. 현재 보유 도메인이 없어 준비된 예제 주소를 공개 실험 결과로 바꿔 적지 않는다.
- 출처와 정상/악성 정답이 있는 실제 문자 자료로 오탐·미탐·미확인율을 별도 평가. 미확인을 정상/악성으로 강제 합산하지 않는다. 동일 링크·사건은 학습/조정용과 최종 평가용에 걸쳐 중복시키지 않는다.
- [KISA 공개 피해예방 자료](https://spam.kisa.or.kr/spam/na/ntt/selectNttInfo.do?bbsId=1101&mi=1221&nttSn=1961)는 택배·지원금 등 URL 유도 유형을 제시하지만, 현재 확인한 본문은 실제 문자 정답 데이터셋이 아니다. 이 유형을 바탕으로 만든 예시는 별도로 합성 시나리오라고 표시해야 한다. 실제 문자 성능 수치를 만들지 않았다.
- 발표용 전체 시나리오 리허설·녹화. 이번 실제 공식 페이지/실패 복구 UI 점검은 부분 리허설이며 전체 시나리오 완료가 아니다.
