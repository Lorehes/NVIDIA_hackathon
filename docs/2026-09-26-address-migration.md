# 공식 주소 이전과 도착 신원 미확인 분리

직전 실제 NHN PlayArt 검사는 공식 명부의 옛 URL에서 HTTP를 거쳐 새 경로로 이동했을 때 출발점의 게임 이름을 도착점에도 강제로 비교하여 caution/domain_not_official을 표시했다. 이번에는 일반 판정과 독립 출처 보완을 나누어 처리한다.

## 일반 규칙

링크만 입력했고 입력 주소가 선택된 기관의 출처 범위와 일치하지만 최종 주소가 미확인이면, 그 사실은 destination_identity_unverified 정보 항목이다. 기관을 문자에서 주장한 경우의 불일치 경고는 그대로 유지한다. 기존 기관 객체는 폼/공유 경계 검사에 유지한다. 실제 다른 등록 경계로 이동·비밀번호 입력·다른 학교 경로 전송·APK 설치 위험은 계속 경고한다. 새 주소의 신원/안전/통신 권한을 승인하는 규칙이 아니다.

결과에는 시작 주소의 공식 출처와 최종 주소 미확인을 분리한다. 출처가 만료되거나 인기 자료뿐이면 시작점 공식 표시도 없다. 페이지 내용 검사/HTTP 중간 연결/실측 TLS 한계는 별도 유지한다. HTTP 경유는 마지막 TLS가 정상이더라도 safe가 될 수 없으며, 반복 재시도 권유 대신 공식 출처와 HTTP 제한을 설명한다.

## 독립 공식 연결

https://www.nhn-playart.com/ 의 제작 게임 목록 링크 /game/ 를 직접 확인했다. 공개 회사 정보/페이지와 기존 NHN 출처를 대조하고, 검토된 link_href 선택자를 수집기 설정으로 관리한다. 광고/다른 경로/질의/하단 임의 링크를 수집하지 않으며 앱 판정에 NHN 호스트 분기는 없다. HTML 해시077154dc84d3e1681718630f13f41c3425dc6271b3d57999d05399dd508f65b6, UTC 확인일2026-09-25.

NHN PlayArt 제작 게임 목록 https://www.nhn-playart.com/game/ 1건을 정확 URL로 추가했다. 기본443 포트 표기는 같은 서비스로 대조하되 다른 경로·질의·비표준 포트는 미확인이다. 게임들의 운영 주체가 모두 같다고 합치거나 HTTP 이동 자체를 신원 근거로 삼지 않는다. 원래3개 게임의 옛 명부 연결도 원출처 그대로 보존한다.
